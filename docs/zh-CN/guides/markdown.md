# Markdown 方言与扩展语法

[English](../../guides/markdown.md) · **简体中文**

Jot 采用面向行级增量编辑且结果可预测的 Markdown 语法规则。常用标准 Markdown 与 GFM 语法开箱即用，同时在物理行段落、代码围栏、引用前缀和列表续行上有明确约定。

## 支持的语法

| 元素 | 写法与说明 |
| --- | --- |
| 标题 | ATX 标题 `# 标题` 至 `###### 标题`（有正文时井号后需跟空格或 Tab）。 |
| 分隔线 | 独立一行写三个或以上相同的 `-`、`*` 或 `_`（标记间允许空格）。 |
| 行内格式 | `**粗体**`、`*斜体*`、`~~删除线~~` 以及 `` `行内代码` ``（代码内保留字面标记）。 |
| 链接与图片 | `[文字](地址)`、`![说明](地址)`、`<https://example.org>`、`<user@example.org>`；支持地址内成对圆括号。 |
| 列表与任务 | 无序列表（`-`、`*`、`+`）、有序列表（`1.`、`1)`）与任务项（`- [ ]`、`- [x]`）。有序列表保留源码中的起始编号。 |
| 数学公式 | 行内公式 `$x+y$` 或 `\(x+y\)`（起止符须在同一物理行）。块公式支持独占一行的 `$$` / `$$`、`\[` / `\]`，以及单行 `\[x+y\]`。 |
| 表格 | GFM 管道表格。表头与分隔行列数必须一致，分隔行每列至少三个 `-`（支持 `:---`、`:---:`、`---:` 对齐）。转义或行内代码中的 `\|` 作为单元格内容保留。 |
| 原始 HTML | 作为纯文本安全显示，不直接注入 DOM。 |

## 关键语法差异

### 按物理行分段

普通物理行各自作为独立段落解析，空行也在语法树中保留明确位置。Jot 不采用 Setext 标题写法——普通文本下一行单写 `---` 会解析为一个段落加一条分隔线。

### 代码围栏

默认情况下，反引号围栏使用三个反引号并在语言名前保留一个 ASCII 空格：

````markdown
``` rust
let count = 3;
```
````

如需在代码块内安全展示另一段裸围栏，可使用 `begin` 与 `end` 显式配对：

````markdown
``` markdown begin
``` rust
let count = 3;
```
``` end
````

波浪号围栏（至少三个 `~`）可直接紧跟语言名，并以不少于开头数量的波浪号结束：

````markdown
~~~~js
const marker = "~~~";
~~~~
````

#### CommonMark 语言名扩展

如果需要像标准 CommonMark 那样把语言名紧跟在反引号后（例如 ```` ```ts ```` 或 ```` ```mermaid ````），可在 `syntaxProfile` 中启用内置扩展：

```ts
syntaxProfile: {
  id: "default",
  version: 1,
  enabledExtensions: [{ id: "commonmark-fence-language", version: "1.0.0" }],
}
```

只留一个光标，放到起始围栏的行末，再按 `Enter` 补齐围栏并进入代码块。已有一对围栏且块内首行为空时，光标直接进入空行。想只换行可以按 `Shift+Enter`，也可以通过 `input: { autoCloseCodeFences: false }` 关闭补全。

打开已有文档时，未闭合的围栏或块公式会保留为普通文本，避免影响后续标题和段落的正常解析。

### 引用块

引用块中的每一物理行都需要带有 `>` 前缀（单独的 `>` 表示引用内的空行）：

```markdown
> 第一层
> > 第二层
>
> 同一个引用中的下一段
已离开引用块
```

每层 `>` 前允许零至三个空格，后面允许一个空格或 Tab；`>> 内容` 与 `> > 内容` 均视为两层引用。引用内支持嵌套标题、列表、表格和闭合代码块（即时预览中引用内的表格保留源码显示，双栏或只读预览可见渲染表格）。

### 列表项内换行

在列表中按 `Enter` 会创建下一项（空列表项按 `Enter` 退回上一级）。在即时预览的已确认列表项中按 `Shift+Enter`，编辑器会自动在行尾补两个空格、换行并缩进到当前项正文起点：

```text
- 第一行··
··仍属于第一项
- 下一项
```

*（`·` 仅用于示意空格位置。）* 手工编写时，续行缩进不少于当前项的正文列即可；若新行以列表标记开头，则会开始新的一项。
